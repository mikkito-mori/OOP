# Анализ архитектуры: Модуль 2 (Крестики-нолики)

## Аудит классов первого модуля

| Класс | Есть общий предок? | Есть магические числа? | Есть логирование? | Какие способности неявны? |
|---|---|---|---|---|
| `Board` | Нет (базовый `object`) | Размер поля `3`, выигрышная линия `3` | Отсутствует | Отрисовка (`Drawable`), обновление состояния (`update`), коллизии/занятость ячеек (`Collidable`) |
| `Player` | Нет (базовый `object`) | Начальный счёт `0`, тайм-ауты ходов | Отсутствует | Отрисовка символа (`Drawable`), совершение хода (`Movable`) |
| `Game` | Нет | Лимит ходов `9`, тайминги задержек | Отсутствует (только print) | Управление циклом сущностей |
